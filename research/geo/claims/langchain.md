# LangChain (LangSmith): claims from its own site

Copied 2026-10-19 from https://www.langchain.com/pricing. Quoted text checked against the live page.

- P1 Developer: "$0 / seat per month", 1 seat, "Up to 5k base traces / mo, then pay-as-you-go".
- P2 Plus: "$39 / seat per month", "Up to 10k base traces / mo, then pay-as-you-go", unlimited seats.
- P3 Enterprise: custom pricing, self-hosted and hybrid options.
- P4 Base traces are kept 14 days, extended traces 180 days.
